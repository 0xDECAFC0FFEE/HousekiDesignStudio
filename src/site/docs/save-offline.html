Saving the studio to your computer

The studio is a single page. Everything it needs – the renderer, the stone, the controls – is inside that one file, so once your browser has loaded it, you can save your own copy to your computer and open it again any time: with no internet connection, and no account.

Why save a copy

  • Keep working with no internet connection – on a plane, or anywhere your connection drops.
  • Keep a version you like exactly as it is, in case a newer one changes something.
  • No account or sign-in is needed. The saved file is yours, on your own computer.

The studio's own File menu does not have a working way to save the page itself – its Save item does not do anything yet. Saving a copy of the studio is done through your browser, the same way you would save any other page.

Saving it

With the studio open in your browser tab, press Ctrl+S (Windows or Linux) or Cmd+S (Mac). This is the most reliable way to reach the save dialog, because browsers move their menus around between versions.

If you would rather use a menu, here is roughly where to look. Choose a location and file name, and pick the option below when your browser asks what to save it as – the studio needs nothing else, so the plainest, single-file option is enough.

BrowserMenuSave as / format
Chrome ⋮ menu (top right) > Cast, save, and share > Save page as… in recent versions – the wording has moved before, so the shortcut above is the reliable option Webpage, HTML only
Edge ⋯ menu (top right) > Save page as…, sometimes under a further More tools menu Webpage, HTML only
Firefox ☰ menu > Save Page As…, or right click the page and choose Save Page As… Web Page, HTML only
Safari File menu > Export As… (called Save As… in some versions) Page Source, not Web Archive

Menu wording changes between browser versions more often than the keyboard shortcut does. If a menu item above is not where this page says, search the browser's own menu for "save page", or use Ctrl+S / Cmd+S instead.

The "HTML only" / "Page Source" options save one plain page file, which is all the studio needs. "Complete" and "Web Archive" also work, but a Web Archive only opens back up in Safari, and a "Complete" save can add an extra folder alongside the file for resources the studio does not actually have – there is nothing this page needs to keep beside it, so the single-file option is the simplest choice.

Opening the saved copy

  • Double click the saved file. It opens in whichever browser your computer opens saved pages with.
  • Or drag the file into an open browser window.
  • Or, from inside a browser, use its own Open File… command and choose the saved file.

What carries over, and what does not

Opening your own design files – File > Open – works exactly the same in a saved copy as it does on the website: it reads the file you choose from your computer, not anything from the internet, so it is unaffected by which copy you are using.

Settings you changed on the website – light or dark mode is the main one today – are remembered by your browser against the website's own address, not against your computer in general. A saved copy lives at a different address entirely (a file on your computer, rather than a page on the web), so it does not see those settings: it opens with its own defaults, the same as a fresh copy on a different computer would. Settings you then change inside a saved copy are remembered by that copy from then on, but they stay with it – they will not appear on the website, or in a different saved copy, even another one made from the same file. Each is its own separate place.

Keeping it up to date

A saved copy is a snapshot: it keeps working exactly as it did the moment you saved it, but it does not update itself. If the studio gains a new feature later, a copy saved before that will not have it – open the website again and save a fresh copy to pick up anything new.

Troubleshooting

ProblemTry this
The saved copy shows a blank page, or an error, when you open it Save it again using the "HTML only" / "Page Source" option (see the table above) rather than "Complete" or "Web Archive", and keep it as that one page file rather than text, an image or a PDF.
The page opens but the stone does not appear, or it shows an error instead of rendering The studio needs a browser with WebGL 2. Most current versions of Chrome, Edge, Firefox and Safari support it, but it can be turned off, or unavailable on some hardware – try a different browser, or check that hardware acceleration is turned on for the one you are using.
